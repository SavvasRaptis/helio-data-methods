# Machine-Learning Problems

Machine learning begins with a question, not an algorithm. Before choosing a
neural network, tree, or optimizer, we need to say what information will be
available and what output is desired.

## Learning objectives

- distinguish classification, regression, and unsupervised questions;
- identify samples, features, targets, predictions, and labels;
- translate a scientific question into a measurable modeling task;
